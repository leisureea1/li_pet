# 🎀 彤彤桌面宠物 (LiTongtong Desktop Pet)

> **“累累，我在这里陪着你哦~”**

彤彤是一个基于 PyQt5 开发的桌面虚拟宠物项目。她不仅能在你的桌面上自由散步、睡觉、求摸摸，还能通过接入 **DeepSeek API** 和 **Edge-TTS** 与你进行生动流畅的语音聊天对话，是你桌面上的完美虚拟女友！

---

## ✨ 核心特性 (Features)

- 🏃‍♀️ **生动的互动动画**
  - **自由散步**：在桌面上左右漫步并带走动弹跳效果。
  - **拖拽飞行**：用鼠标拖拽彤彤，她会在空中挣扎倾斜，还会惊呼“飞起来啦！”
  - **点击互动**：点击会有专属随机对话，摸摸头会有舒适的动画，睡觉时会飘出可爱的 `Zzz` 气泡。
  - **文件解读**：支持将文本文件拖拽给彤彤，她会自动阅读并给出专属的回应。

- 💬 **智能语音对话 (DeepSeek + Edge-TTS)**
  - **上下文记忆**：接入了强大的 DeepSeek API，通过长期加密记忆技术，彤彤会一直记得你们聊过的话题。
  - **情感语音**：无缝对接微软 Edge-TTS (zh-CN-XiaoxiaoNeural)，每一句聊天都会自动转为甜美的语音播报。
  - **系统状态感知**：彤彤能够感知你电脑当前的 CPU 和内存负载，并在过载时贴心提醒你。
  - **专属闹钟/备忘录**：可以对彤彤说“10分钟后提醒我喝水”，她会自动设置定时器到点提醒你。

- 🔒 **安全与隐私**
  - **本地数据加密**：所有的 API 密钥、配置文件以及聊天历史，均经过 Base64 + XOR 算法加密后存放在 `APPDATA` 目录下，保护你的隐私。
  - **资源内嵌加密**：打包时采用静态内嵌的方式，防止本地图片或资源被篡改替换。

- ⚙️ **丰富的自定义设置**
  - 提供极其可爱的定制化 `无边框设置界面`。
  - 支持快捷配置 DeepSeek API Key。
  - 支持静音模式与开机自启动设置。

## 🛠️ 安装与运行 (Installation)

### 方法一：下载免安装版 (推荐)
直接在项目的 **Releases** 页面下载最新构建的 `LiTongtong_Setup.exe`，双击即可无脑安装并运行。

### 方法二：从源码运行

如果你希望二次开发，可以通过以下步骤在本地运行：

1. **克隆项目**
   ```bash
   git clone https://github.com/leisureea1/li_pet.git
   cd li_pet
   ```

2. **安装依赖**
   建议使用 Python 3.8+ 版本：
   ```bash
   pip install -r requirements.txt
   ```
   *(注意：如果您在国内安装 `edge-tts` 时遇到 SSL 证书错误，请尝试配置代理或使用清华镜像源 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple edge-tts`)*

3. **运行程序**
   ```bash
   python pet.py
   ```

## 📦 打包项目 (Build)

本项目集成了 `pyinstaller` 和 `NSIS`，可以使用根目录下的 `build_exe.bat` 一键打包生成独立的安装程序。
另外，项目的 `.github/workflows/build.yml` 配置了完整的 CI/CD 自动化流水线。当你推送到 `main` 分支时，GitHub Actions 会自动为你编译并生成跨平台的构建包。

## 💖 使用说明 (How to use)

- **右键菜单**：右键点击彤彤可以唤起全功能菜单。你可以让她去睡觉、跟随鼠标、摸摸头、喂吃的，也可以进入设置页面。
- **对话方式**：右键选择“陪我聊聊天”，会弹出一个半透明输入框，输入你想说的话并按回车即可。
- **配置 API**：初次运行后，请右键进入 **⚙️ 设置**，填入你的 DeepSeek API Key 才能唤醒她的灵魂哦。
