# 🎀 彤彤桌面宠物 (LiTongtong Desktop Pet)

> **“累累，我在这里陪着你哦~”**

彤彤是一个基于 PyQt5 开发的**轻量级桌面 AI Agent** 虚拟宠物项目。她不仅能在你的桌面上自由散步、睡觉、求摸摸，还能通过接入 **DeepSeek API** 和 **Edge-TTS** 与你进行生动流畅的带有情绪的语音聊天对话，是你桌面上的完美虚拟女友！

---

## ✨ 核心特性 (Features)

- 🏃‍♀️ **生动的互动与情绪动画**
  - **自由散步**：在桌面上左右漫步并带走动弹跳效果。
  - **拖拽飞行**：用鼠标拖拽彤彤，她会在空中挣扎倾斜，还会惊呼“飞起来啦！”
  - **情绪感知**：彤彤能够通过 AI 自主分析语境，并通过 `[EMOTION:xxx]` 标签驱动屏幕上的不同动画（如开心跳动、困倦打哈欠、生气鼓腮帮等）。
  - **点击互动**：点击会有专属随机对话，摸摸头会有舒适的动画，睡觉时会飘出可爱的 `Zzz` 气泡。
  - **文件解读**：支持将文本文件拖拽给彤彤，她会自动阅读并给出专属的回应。

- 💬 **智能语音对话 (DeepSeek + Edge-TTS)**
  - **上下文长期记忆**：接入了强大的 DeepSeek API，通过基于 SQLite 的**自动记忆提取技术**，彤彤会默默记下你的喜好，一直记得你们聊过的话题。
  - **情感语音**：无缝对接微软 Edge-TTS，聊天不仅会自动转为甜美的语音播报，还会根据彤彤的 `[EMOTION:xxx]` 情绪标签**自动调节语速和音调**！
  - **本地向量语义路由 (Semantic Router)**：纯本地集成了 ONNX 格式的 `bge-small-zh-v1.5` 微型大模型。用户输入的对话能在数毫秒内完成意图打分与路由分发，精准拦截 API 工具请求，大幅减少无效的大模型 Token 消耗！

- 👁️ **高级环境感知与主动陪伴 (Advanced Companion AI)**
  - **真正的操作系统级侦测 (OS-Level)**：不再是简单的定时器！内置了 `psutil` 侦测 CPU 狂转、以及 `ctypes` 监听 Windows 底层键鼠活跃度。
  - **场景识别**：精确识别你的场景。比如：代码编译/下载等待、长达 90 分钟以上的真正“久坐”、凌晨的“熬夜”、看 B站/Netflix 视频、甚至能秒级识别你在听什么歌！
  - **极低消耗的陪伴大脑**：我们通过拆分出独立的 `CompanionThread`，让彤彤在观察到你切歌或换窗口时，能以低于 400 Tokens 的极小代价，秒级弹出带有情绪颜文字的贴心气泡。她有着强烈的占有欲和丰富的脑补想象力，陪伴感直接拉满！

- 📊 **本地 Token 可视化面板**
  - 内置了一个微型 Web 服务器，只需在浏览器打开 `http://127.0.0.1:5050`，就能看到精美的折线图和饼图，实时监控各种聊天场景（如主动陪伴、技能工具、闲聊）的 Token 消耗和系统状态！

- 🧩 **高扩展的技能插件系统 (Skill System)**
  - **自主调用**：利用 DeepSeek 的 Function Calling，彤彤可以在聊天过程中**自主决定**调用哪些技能（如查询天气、百科搜索、系统闹钟提醒、计算器等）。
  - **热插拔开发**：系统支持独立于核心之外的插件架构。只需在 `skills/` 目录下编写简单的 Python 脚本即可快速给彤彤赋予新的能力（如控制电脑、获取汇率等）。通过 `skills.json` 即可随时开启或禁用技能。

- 🔒 **安全与隐私**
  - **本地数据加密**：所有的 API 密钥、配置文件以及聊天历史，均经过 Base64 + XOR 算法加密后存放在 `APPDATA` 目录下，保护你的隐私。
  - **纯净的架构**：项目经过彻底的大重构，拥有极其干净的 `core/` 底层大脑，解耦了 PyQt 渲染与 AI 逻辑，方便二次开发。

- ⚙️ **丰富的自定义设置**
  - 提供极其可爱的定制化 `无边框设置界面`。
  - 支持快捷配置 DeepSeek API Key。
  - 支持静音模式与开机自启动设置。

## 🛠️ 安装与运行 (Installation)

### 方法一：下载免安装版 (推荐)
直接在项目的 **Releases** 页面下载最新构建的 `LiTongtong_Setup.exe`，双击即可无脑安装并运行。

### 方法二：从源码运行

如果你希望二次开发，可以通过以下步骤在本地运行：

1. **克隆项目**
   ```bash
   git clone https://github.com/leisureea1/li_pet.git
   cd li_pet
   ```

2. **安装依赖**
   建议使用 Python 3.8+ 版本：
   ```bash
   pip install -r requirements.txt
   ```
   *(注意：如果您在国内安装 `edge-tts` 时遇到 SSL 证书错误，请尝试配置代理或使用清华镜像源 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple edge-tts`)*

3. **运行程序**
   ```bash
   python pet.py
   ```

## 📦 架构说明与打包 (Architecture & Build)

### 目录结构
```text
li_pet/
├── pet.py            # 入口与纯粹的 PyQt5 UI 驱动层
├── core/             # 系统大脑 (配置、记忆提取、AI 通信、技能分配)
├── skills/           # AI 技能插件目录（如 weather.py, search.py）
├── skills.json       # 技能白名单配置
└── requirements.txt  # 依赖表
```

### 自动化打包
本项目集成了 `pyinstaller` 和 `NSIS`，项目的 `.github/workflows/build.yml` 配置了完整的 CI/CD 自动化流水线。当你推送到 `main` 分支时，GitHub Actions 会自动为你编译包含 `core/` 模块和 `skills/` 模块的跨平台构建包。

## 💖 使用说明 (How to use)

- **右键菜单**：右键点击彤彤可以唤起全功能菜单。你可以让她去睡觉、跟随鼠标、摸摸头、喂吃的，也可以进入设置页面。
- **对话方式**：右键选择“陪我聊聊天”，会弹出一个半透明输入框，输入你想说的话并按回车即可。
- **使用技能**：直接对彤彤说“帮我查一下北京明天的天气”、“10分钟后提醒我休息”，她会自动为你执行！
- **配置 API**：初次运行后，请右键进入 **⚙️ 设置**，填入你的 DeepSeek API Key 才能唤醒她的灵魂哦。
